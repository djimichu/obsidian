# Топик - 

логический канал для хранения сообщений. Есть Producer(писатель) и Consumer(читатель)

У каждого Consumer есть свой уникальный offset - сколько было прочитано из топика. То есть если на один топик подписаны несколько Consumers, то мы всегда знаем сколько записей прочитал каждый из них.
