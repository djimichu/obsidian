# Docker Volume.

Docker Volume решает проблему потери данных при завершении работы контейнеров. То есть например у нас есть БД в контейнере и если его остановить мы потеряем все файлы с данными. Docker Volume смапливает(map - сопоставлять) файлы из контейнера с нашим компьютером и все файлы после остановки контейнера останутся у нас. 

Допустим у нас есть image "volumetest", чтобы запустить контейнер с Docker Volume:
```bash
docker run --volume ./out:/app/out volumetest
# первой папкой пишем то, куда будут смаплены файлы относительно терминала(./out), а через : пишем путь относительно нашего контейнера(/app/out)
```
> Лучше не создавать самому руками папку, ее создаст контейнер


Собираем всё вместе:

```bash
docker run -e POSTGRES_PASSWORD=pass -p 5432:5432 -d postgres:18-bookworm
# -e: задаем пароль для БД через переменную окружения(env)
# -p: пробрасываем порты на наш комп
# -d: deteached mode, свободный терминал
```
Но мы забыли сохранить файлы, чтобы они не сбрасывались.
```bash
docker run -e POSTGRES_PASSWORD=pass -p 5432:5432 -v ./out/pgdata:/var/lib/postgresql -d postgres:18-bookworm
# ./out/pgdata это то, куда мы сохраняем, а /var/lib/postgresql это то, где находятся наши файлы в контейнере, именно БД
```
