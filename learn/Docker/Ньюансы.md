Когда мы вызываем `go run main.go` происходит две вещи:
```bash
go build -o exe main.go # компилируем исполняемый файл(бинарный код)
# и
./exe # запустить исполняемый файл
```
И после этот файл удаляется.

Суть в том, что в контейнере у нас один образ, то есть никаких изменений нет, а значит нам не нужно каждый раз создавать и удалять исполняемый файл, нам было бы выгоднее его оставить и каждый раз запускать один файл.

Следовательно в в Dockerfile мы вызываем `RUN go build -o /app/exe main.go`, и при запуске приложения просто вызывать скомпилированный файл:
```docker
CMD ["/app/exe"]
```
Теперь программа будет каждый раз запускаться быстрее чем раньше.
