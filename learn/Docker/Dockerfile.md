# Создаем Dockerfile

Dockerfile - инструкция для создания заготовки(image/образа)

```docker
FROM golang:1.24-bookworm
```
Сперва мы берем изначальный базовый образ, есть разные: alpine, trixie, bookworm и тд, берем что нужно(bookworm лучше всего), также выбираем нашу версию go.

Затем нам нужно создать рабочую директорию внутри нашего контейнера в которой будет производится вся дальнейшая работа:
```docker
WORKDIR /app
```

```docker
COPY . .
```

Прокидываем все наши файлы внутри докер-контейнера. Первая точка означает все наши файлы и директории, вторая точка означает что копируем в корень /app

Также нам нужно скопировать все наши зависимости(внешние пакеты) из go.mod
```docker
RUN go mod tidy
```

И финальной командой будет запуск:
```docker
CMD ["go", "run", "main.go"]
```
Либо команду запуска из Makefile(если есть). Нужно писать как массив строк(хз зачем, такое требование)

## Собираем образ(image)

Чтобы по этой инструкции создать image/образ, надо написать в корне проекта(при условии что видно Dockerfile при команде ls)
```bash
docker build . -t study-http-image # -t дает возможность дать имя нашему image
```

Ждем загрузки образа и пишем ``docker image ls`` мы должны будем увидеть наш study-http-image

Теперь по имени study-http-image мы можем запустить этот image:
```bash
docker run study-http-image
```

Чтобы *выйти* из docker-контейнера пишем `exit` 

Чтобы посмотреть какие docker-контейнеры *сейчас запущены* мы пишем `docker ps`

Мы можем оказаться в терминале нашего контейнера, прямо с директории /app, для этого:
```bash
docker exec -it eloquent_chandrasekhar /bin/bash
```
Именно отсюда можно обращаться к порту нашего проекта, а не из терминала нашего компа.

Чтобы связать наш порт и порт контейнера мы можем убить(остановить) старый контейнер(`docker kill eloquent_chandrasekhar`), затем написать:
```bash
docker run -d -p 5050:5050 study-http-image 
# -d не блокирует терминал, информация в логах
# -p пробрасываем порты 
```
Так мы пробрасываем порт контейнера на наш порт 5050, логи смотрим командой
```bash
docker logs eloquent_chandrasekhar
```

## Как изменить код в docker-контейнере.

Если мы просто изменим код и запустим новый контейнер из старого docker-образа, то никаких изменений не получим на деле. Нам надо пересобрать сам image чтобы изменения появились.
