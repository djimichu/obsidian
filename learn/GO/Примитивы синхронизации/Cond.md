##### `Cond` — это механизм:

> “Если условие не выполнено — жди. Когда состояние изменится — тебя разбудят.”

Он нужен, когда одной блокировки (`Mutex`) недостаточно.

`Mutex` только запрещает одновременный доступ.  
`Cond` позволяет **ждать изменения состояния**.

---

### 2️⃣ Зачем он вообще нужен

Представь очередь задач.

Есть:

- производитель (кладёт задачи)
    
- потребитель (забирает задачи)
    

Если очередь пустая, потребитель не должен:

- крутиться в бесконечном цикле
    
- жрать CPU
    

Он должен:

> заснуть и проснуться, когда появится задача.

Вот для этого и нужен `Cond`.

---

### 3️⃣ Как он устроен

`Cond` всегда используется вместе с `Mutex`.

Внутри у него:

- список ожидающих горутин
    
- ссылка на `Locker` (обычно `Mutex`)
    
- механизм “усыпить/разбудить” через рантайм

```go
func main() {  
	var mu sync.Mutex  
	cond := sync.NewCond(&mu)  
  
	ready := false  
	  
	// Горутинa, которая ждёт  
	go func() {  
		mu.Lock()  
		for !ready {  
			cond.Wait()  
		}  
		// иллюзия работы:
		fmt.Println("Готово!")  
		mu.Unlock()  
	}()  
	  
	// Горутинa, которая через 2 секунды меняет состояние  
	go func() {  
		time.Sleep(2 * time.Second)  
		  
		mu.Lock()  
		ready = true  
		cond.Signal()  
		mu.Unlock()  
	}()  
	  
	time.Sleep(3 * time.Second)  
}
```
