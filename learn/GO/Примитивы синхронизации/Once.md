# `sync.Once` — “сделай один раз, даже если одновременно вызывают 100 горутин”

## Зачем нужен

Когда у тебя есть что-то, что должно быть создано/загружено **ровно один раз**:

- конфиг
    
- подключение к базе
    
- инициализация кэша
    
- загрузка справочника
    

Если ты сделаешь так:

```go
if cfg == nil { cfg = load() }
```

— это **небезопасно**: 2 горутины могут одновременно увидеть `nil` и обе загрузят.

## Как использовать (минимум)

```go
var once sync.Once  
var cfg *Config  
  
func GetConfig() *Config {  
    once.Do(func() {  
        cfg = loadConfig()  
    })  
    return cfg  
}
```

## Что важно на собесе

- `Do()` гарантирует, что функция выполнится **один раз**
    
- остальные горутины, пришедшие одновременно, **подождут**, пока первая закончит
    
- результат будет корректно виден всем (порядок памяти соблюдён)
