#### Что происходит “внутри” (понятными словами)

Внутри у `WaitGroup` есть:

1. **счётчик** (сколько задач ещё не закончено)
    
2. механизм “усыпить/разбудить” (чтобы `Wait()` не жрал процессор)
    

###### Когда ты вызываешь `Wait()`:

- если счётчик > 0:
    
    - горутина, которая вызвала `Wait()`, **усыпляется**
        
    - планировщик её снимает с выполнения
        
- когда другие горутины вызовут `Done()` достаточно раз и счётчик станет 0:
    
    - рантайм **будит** ожидающую горутину
        
    - она продолжает выполнение **со строки после `Wait()`**
        

---

### Мини-сценарий

1. `wg.Add(2)` → счётчик = 2
    
2. запускаешь две горутины
    
3. main доходит до `wg.Wait()`:
    
    - счётчик 2 → main-горутина “засыпает” прямо здесь
        
4. первая горутина закончила → `Done()` → счётчик = 1
    
5. вторая закончила → `Done()` → счётчик = 0
    
6. **в этот момент** `Wait()` “разморозится” и main продолжит дальше
