# Distributed Locking

- Гарантирует **одного владельца** для общего ресурса/задачи
- Синхронизация между **потоками/инстансами/сервисами**
- Предотвращает **гонки** и **дублирование работы**

## Паттерн

- Все инстансы пытаются взять блокировку по ключу
- Лок можно захватить, только если он никем еще не захвачен
- Кто взял лок - выполняет работу; остальные **ждут/ретраят/фейлятся**
- TTL обязателен (защита от deadlock)

Всего есть два метода - **TryLock и Unlock**
То есть мы либо пробуем взять блокировку, либо разблокируем уже имеющуюся. 

В захвате блокировки мы ставим уникальный токен(будь то ID транзакции, товара и тд)
Также добавляем TTL
