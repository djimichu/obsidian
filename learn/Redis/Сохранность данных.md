# Сохранность данных в Redis.

Все данные, которые Redis хранит на оперативке могут просто исчезнуть при перезапуске сервера. Чтобы избежать потерю данных есть два стандартных способа Redis'а.

### RDB (snapshot)

   "Снимки" состояния базы данных
   - dump.rdb файл
   - Периодически снимки памяти на диск (N сек / M изменений)
   - Меньше IO, но потеря данных до последнего снапшота(условно снимок раз в час)
### AOF (append only file)

   "Журнал" операций записи
- appendonly.aof файл
- Логирует каждую Write-команду в файл
- Режимы fsync: always / everysec / no (компромисс скорость <-> потери)


### Как работает обычно

- Часто включают **оба**: RDB + AOF everysec
- Нет строгой гарантии 0-потерь: при ***everysec*** риск потерять <= 1 секунды
- Redis не гарантирует сохранность всего(кроме always)
