# Инициализация.
Чтобы создать локальный репозиторий мы пишем:
```bash
git init
```
# Связываем с GitHub
Чтобы связать локальный и удаленный репозиторий:
```bash
git remote add origin git@github.com:*username*/*name*.git
```

# GIT ADD

Далее нам нужно добавить файлы в commit:
```bash
git add main.go          #добавляем только main.go
git add .                #добавляем все файлы в проекте
```

> [!warning]- .gitignore
> 
> ![[Pasted image 20260111123012.png]]
> Зеленым будет отображаться файл, который добавлен в коммит.
> Оранжевым - что не добавлено, так как мы вписали в .gitignore

# Откат на коммит.

Если мы написали что-то и хотим откатиться до последнего нашего коммита, мы можем это сделать прямо в IDEшке без команд в разделе Commit. Это будет называться Rollback.
Либо можно из терминала(рекомендуется):
```bash
git restore .      # . откатит все файлы до коммита, можно по одному файлу
```


# GIT PUSH. Первый пуш на ветке

Чтобы синхронизировать наш коммит с удаленным репозиторием на GitHub нам нужно сделать следующее:
```bash
git push --set-upstream origin master 
  #только первый пуш, создаем любую ветку на GitHub
```
в первый раз может спросить, точно ли доверяем SSH GitHub.

# GIT MERGE/PULL REQUEST

Мы скачали себе последний коммит мастер ветки проекта с GitHub репозитория, затем мы создаем ветку для работы с ней:
```bash
git branch new_branch abcd1234
```

Теперь у нас есть ветка под названием new_branch, чтобы переключится на нее мы пишем:
```bash
git checkout new_branch
```

И вот тут уже мы работаем с нашим проектом, создаем коммиты, делаем pull request и тд.
Когда мы сделали работу и нам надо залить в master ветку изменения, мы делаем pull request:
мы заливаем нашу рабочую ветку в GitHub
git push --set-upstream origin new_branch 
после этого заходим на GitHub и там будет ==Compare & pull request==, либо же мы можем вручную выбрать ==New pull request==(тут нужно будет выбрать ветку в которую мы сливаем нашу ветку и собственно нашу ветку)

Потом наши коллеги оценят наш код, возможно добавят какие-то комментарии по исправлению и мы можем делать новые коммиты и пушить их в GitHub. Если pull request одобрен, то чтобы подтянуть те новые коммиты с GitHub, нужно написать
git pull
