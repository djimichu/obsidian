## 📦 Введение в массивы

**Что такое массив в PostgreSQL?**  
Это коллекция значений одного типа, хранящаяся в одной колонке таблицы. Как коробка с ячейками, где в каждой ячейке — одно значение.

```sql
-- Создадим таблицу с массивом
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name TEXT,
    emails TEXT[],  -- "массив текстов"
    phone_numbers TEXT[],
    scores INTEGER[]
);
```

## 🎯 Инициализация и базовые операции
#### Создание массива:
```sql
-- 1. Через фигурные скобки (самый частый способ)
SELECT ARRAY['a', 'b', 'c'];  -- => {a,b,c}

-- 2. Через конструктор ARRAY[]
SELECT ARRAY[1, 2, 3];  -- => {1,2,3}

-- 3. Из подзапроса
SELECT ARRAY(SELECT id FROM users LIMIT 3);
```
#### Вставка данных:
```sql
INSERT INTO users (name, emails, scores) 
VALUES (
    'Алиса',
    '{"personal@mail.com", "work@company.com"}',  -- JSON-подобный синтаксис
    '{95, 87, 92}'  -- или можно так
);

-- Или так:
INSERT INTO users (name, emails) 
VALUES (
    'Боб',
    ARRAY['bob@gmail.com', 'bob@yahoo.com']
);
```

#### Доступ к элементам:

```sql
-- Индексация с 1 (не с 0 как в Go!)
SELECT emails[1] FROM users;  -- Первый email
SELECT emails[2] FROM users;  -- Второй email

-- Изменение элемента
UPDATE users 
SET emails[2] = 'new@email.com' 
WHERE id = 1;
```



## 🍰 Срезы (slices)

Работают почти как в Go, но с 1-базовой индексацией:
```sql
SELECT emails[1:3] FROM users;  -- Элементы с 1 по 3(включительно)
SELECT emails[2:] FROM users;   -- Все элементы со 2-го до конца
SELECT emails[:3] FROM users;   -- Первые 3 элемента
```


## 🔍 Операторы для работы с массивами

#### Проверка наличия элемента:

```sql
-- Есть ли значение в массиве?
SELECT * FROM users 
WHERE 'work@company.com' = ANY(emails);  -- ANY = "любой из"

-- Нет ли значения в массиве?
SELECT * FROM users 
WHERE 'spam@mail.com' != ALL(emails);  -- ALL = "все"

-- Содержит ли массив все указанные значения?
SELECT * FROM users 
WHERE emails @> ARRAY['work@company.com'];  -- @> = "содержит"

-- Пересекается ли с другим массивом?
SELECT * FROM users 
WHERE emails && ARRAY['work@company.com', 'gmail.com'];  -- && = "пересекается"
```
#### Сравнение массивов:

```sql
-- Полное совпадение (порядок важен!)
SELECT ARRAY[1,2,3] = ARRAY[1,2,3];  -- true
SELECT ARRAY[1,2,3] = ARRAY[1,3,2];  -- false

-- Можно сравнивать поэлементно
SELECT ARRAY[1,2,3] < ARRAY[1,2,4];  -- true (лексикографическое сравнение)
```

## 📏 Функции для работы с массивами

```sql
-- Длина массива
SELECT array_length(emails, 1) FROM users;  -- Первое измерение

-- Или проще:
SELECT cardinality(emails) FROM users;  -- Общее количество элементов

-- Добавить элемент в конец
UPDATE users 
SET emails = array_append(emails, 'extra@mail.com');

-- Удалить все вхождения элемента
UPDATE users 
SET emails = array_remove(emails, 'old@mail.com');

-- Объединить массивы
SELECT array_cat(ARRAY[1,2], ARRAY[3,4]);  -- => {1,2,3,4}

-- Найти позицию элемента (вернет 0 если нет)
SELECT array_position(emails, 'work@company.com') FROM users;

-- Уникальные значения
SELECT array( SELECT DISTINCT unnest(scores) FROM users );
```

## 🌀 UNNEST - "развертывание" массива

Работает по сути на основе JOIN

```sql
-- Было: одна строка с массивом {a,b,c}
-- Стало: три строки со значениями a, b, c
SELECT unnest(ARRAY['a', 'b', 'c']);

-- Практический пример: найти всех пользователей по списку ID
SELECT * FROM users 
WHERE id = ANY(ARRAY[1, 5, 10]);

-- Или через UNNEST для JOIN:
SELECT u.* 
FROM unnest(ARRAY[1, 5, 10]) AS user_id(id)
JOIN users u ON u.id = user_id.id;
```

## 🛠 VARIADIC параметры в функциях

Позволяют передавать переменное количество аргументов как массив:
```sql
-- Создаем функцию с VARIADIC
CREATE FUNCTION sum_all(VARIADIC nums INTEGER[]) 
RETURNS INTEGER AS $$
BEGIN
    RETURN (SELECT SUM(n) FROM unnest(nums) AS n);
END;
$$ LANGUAGE plpgsql;

-- Вызываем с любым количеством аргументов
SELECT sum_all(1, 2, 3);       -- => 6
SELECT sum_all(1, 2, 3, 4, 5); -- => 15

-- Можно и массив передать явно
SELECT sum_all(VARIADIC ARRAY[1,2,3]);
```


## 🔄 FOREACH цикл в PL/pgSQL

Итерация по элементам массива внутри функций:
```sql
CREATE FUNCTION print_emails(user_emails TEXT[]) 
RETURNS VOID AS $$
DECLARE
    single_email TEXT;
BEGIN
    FOREACH single_email IN ARRAY user_emails
    LOOP
        RAISE NOTICE 'Email: %', single_email;
    END LOOP;
END;
$$ LANGUAGE plpgsql;

-- Вызов
SELECT print_emails(ARRAY['test@mail.com', 'admin@mail.com']);
```

## 🏆 Ключевые отличия от Go

1. **Индексация с 1**, а не с 0
    
2. **Фигурные скобки `{}`** вместо квадратных `[]` для литералов
    
3. **Тип указывается как `TEXT[]`**, а не `[]TEXT`
    
4. **Размер не фиксирован** (как слайс в Go, не как массив)
    
5. **Может быть многомерным**: `INTEGER[][]` (массив массивов)
