## Всё о DDL.

1. [[learn/00. postgreSQL/04. DDL/Введение|Введение]] - CREATE TABLE, ALTER TABLE, DROP TABLE, TRUNCATE, а также задачи.

2. [[PRIMARY KEY]] - первичный(внутренний ключ).
3. [[FOREIGN KEY]] - внешний ключ
4. [[Ограничения]] - CHECK, DEFAULT, ограничения для вставки данных.
5. [[Последовательность]] - SEQUENCE, как работает serial, счетчик уникальностей.
6. [[INSERT]] - вставка данных в таблицу.
7. [[UPDATE, DELETE]] - обновление и удаление данных в таблице, а также RETURNING.
