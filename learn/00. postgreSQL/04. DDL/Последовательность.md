## Последовательность SEQUENCE

Когда мы создаем колонку с типом данных `serial`, то postreSQL сам будет отслеживать и генерировать значение для этого столбца с автоматическим инкрементом. Тут мы разберем, как работает этот `serial`

Мы можем явно создавать и манипулировать SEQUENCE(последовательность). Это может быть полезно не только для понимания устройства работы, но и в дальнейшем может помочь в программировании.

> [!example] Создадим последовательность
> ```sql
> CREATE SEQUENCE IF NOT EXISTS seq1;
> ```
> 

- Для того чтобы сгенерировать следующее значение нужно вызвать nextval - сгенерирует 1
- Чтобы получить текущее значение, есть функция currval - покажет ту же 1
- И lastval вернет нам последнее сгенерированное значение какой-либо из последовательностей в этой сессии (не относится к определенной последовательности)

> [!example] Пример
> 
> ```sql
> SELECT nextval('seq1'); -- генерируем следующее значение последовательности
> SELECT currval('seq1'); -- получаем текущее
> SELECT lastval(); -- получаем последнее сгенерированное
> ```

Также мы можем явно манипулировать значением последовательности, задавая его через setval('seq', значение, true/false)

> [!example] Пример
> 
> ```sql
> SELECT setval('seq1', 16, true); -- делаем текущее значение 16
> SELECT currval('seq1'); -- получим те же 16
> SELECT nextval('seq1'); -- сгенерируем 17
> ```

> Как мы видим в параметрах функции есть true/false, вся разница в том, что при true мы говорим, что значение которое мы передали (16) уже выдали и nextval даст N+1 (17),
> а false будет означать, что мы еще не выдали и при nextval даст нам N.

Еще мы можем делать для SEQUENCE и другие параметры, такие как increment(шаг, прирост),
maxvalue, minvalue

> [!example]- Создаём последовательность с параметрами
> ```sql
> CREATE SEQUENCE IF NOT EXISTS seq2
> INCREMENT 16
> MINVALUE 0,
> MAXVALUE 128
> START WITH 0;
> 
> SELECT nextval(seq2);
> ```

> Тут у нас получится, что мы начнём с 0, будем с каждым выполнением nextval прибавлять по 16 (16, 32, 48, 64 и т.д.), пока не достигнем максимального значения 128. И если после этого мы попробуем еще раз выполнить nextval, то будет ошибка SQL state: 2200H


> [!example] Мы можем переименовать наш SEQUENCE
> ```sql
> ALTER SEQUENCE seq2 RENAME TO seq3;
> ```

> [!example] Можем зарестартить последовательность
> ```sql
> ALTER SEQUENCE seq3 RESTART WITH 16;
> ```

> [!example] Или удалить последовательность
> ```sql
> DROP SEQUENCE seq3;
> ```



---

Чтобы заменить serial типом int можно написать такой код:

> [!example]-
> ```sql
> -- предположим уже создали таблицу и колонку book_id int NOT NULL
> CREATE SEQUENCE IF NOT EXISTS book_book_id_seq
> START WITH 1 OWNED BY book.book_id;
> -- но так у нас не будет заполняться это поле автоматически, добавляем:
> ALTER TABLE book
> ALTER COLUMN book_id SET DEFAULT nextval('book_book_id_seq')
> ```
Это просто для понимания 

Если кто-то вставит самостоятельно значение в SEQUENCE, ну вот например человек решил взять и вставить (book_id, title, isbn, publisher_id), то оно вставится, но в следующий, когда он вставит другую запись без указания book_id, то произойдет ошибка, так как наша последовательность не знает о том, что он вставлял запись и начнутся проблемы.

На деле используется такой способ:


> [!example]- GENERATED
> ```sql
> CREATED TABLE
> (
> 	book_id int GENERATED ALWAYS AS IDENTITY NOT NULL,
> 	title text NOT NULL,
> 	isbn varchar(32) NOT NULL,
> 	publisher_id int NOT NULL
> )
> ```

> Теперь если он захочет вставить book_id просто так, то он получит ошибку
> SQL state: 428C9 ERROR: вставить данные в столбец book_id нельзя

Однако это не значит, что теперь туда вовсе нельзя вставлять данные самому. Можно, сказав:

> [!example]- OVERRIDING SYSTEM VALUE
> ```sql
> INSERT INTO book
> OVERRIDING SYSTEM VALUE
> VALUES (3, 'title2', 'isbn2', 1)
> ```


Еще касаемо GENERATED мы можем написать BY DEFAULT и мы снова сможем сами добавлять данные в этот столбец без всяких вышеупомянутых конструкций. Также мы можем указывать параметры этого столбца:

> [!example]- Добавляем параметры для book_id
> ```sql
> CREATED TABLE
> (
> 	book_id int GENERATED ALWAYS AS IDENTITY (START WITH 10 INCREMENT BY 2) NOT NULL,
> 	title text NOT NULL,
> 	isbn varchar(32) NOT NULL,
> 	publisher_id int NOT NULL
> )
> ```
> Айдишник будет начинаться с 10 и далее по +2

Также при каких-то изменениях этой колонки нам не надо писать и знать имя SEQUENCE. Мы просто всё делаем через ALTER TABLE и т.д. 

Именно GENERATED мы и будем везде использовать!
