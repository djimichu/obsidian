## INSERT

INSERT как уже стало понятно, нужен для вставки данных в таблицу.

```sql
INSERT INTO таблица
VALUES
(значение_1, значение_2)
```

Если мы хотим вставить не все данные, идущие по порядку, то обязательно нужно указать, что мы вставляем:
```sql
INSERT INTO таблица (title, isbn, publisher_id)
VALUES
(значение_1, значение_2, значение_3)
```

Мы можем создавать таблицу и сразу вставлять в неё какую-либо выборку(backup) с помощью следующего синтаксиса:
```sql
SELECT *
INTO best_authors -- Пишем название таблицы которую создаем
FROM author -- Из таблицы "авторы"
WHERE rating >= 4.5 -- Только тех, чей рейтинг не менне 4.5
```

Получаем новую таблицу, из которой мы можем посмотреть данные как из любой другой таблицы

Чтобы вставить теперь другую выборку в уже существующую таблицу, мы пишем так:

```sql
INSERT INTO best_authors -- Название таблицы в которую вставляем
SELECT *
FROM author
WHERE rating < 4.5 -- Включаем всех остальных
```
