# Введение.

В данном разделе мы разберем два типа функций в Postgres

- SQL-функции
- Процедурные (PL/pgSQL - основной диалект)

Простейший синтаксис создания функции:
1. ```sql
	CREATE FUNCTION func_name([arg1, arg2...]) RETURNS data_type AS $$
	--logic
	$$ LANGUAGE lang
	```
> Аргументы необязательны. Два значка доллара \$$ открывают тело функции.


Также мы можем обновить существующую функцию:

2. 
	```sql
	CREATE OR REPLACE FUNCTION func_name...
	```
> Ограничения на изменения примерно те же что и у View
