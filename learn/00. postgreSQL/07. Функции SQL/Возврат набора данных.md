## Возврат набора данных.

Есть несколько вариантов возврата нескольких значений:

- `RETURNS SETOF` *data_type* - возврат n-значений типа *data_type*
- `RETURNS SETOF` *table* - если нужно вернуть все столбцы из таблицы или пользовательского типа
- `RETURNS SETOF` **record** 
	- только когда типы колонок в результирующем наборе заранее неизвестны
	- лучше не использовать
- `RETURNS TABLE`(*column_name* data_type, ...) - тоже что и `SETOF` *table*, но имеем возможность явно указать возвращаемые столбцы
- Возврат через out-параметры

> [!example]- RETURNS SETOF *data_type*
> ```sql
> CREATE OR REPLACE FUNCTION get_avarage_prices_by_prod_categories()
> 		RETURNS SETOF double precision AS $$
> 		
> 	SELECT AVG(unit_price)
> 	FROM products
> 	GROUP BY category_id
> 	
> $$ LANGUAGE SQL;
> 
> SELECT * FROM get_avarage_prices_by_prod_categories() AS avg_prices;
> ```
> 
> Мы получаем одну колонку, в которой разбиты по категориям(мы их не видим) средние цены товаров

> [!example]- RETURNS SETOF *RECORD*
> ```sql
> CREATE OR REPLACE FUNCTION get_avg_prices_by_prod_categories(
> 		OUT sum_price real,
> 		OUT avg_price float8
> )
> 		RETURNS SETOF RECORD AS $$
> 		
> 	SELECT SUM(unit_price), AVG(unit_price)
> 	FROM products
> 	GROUP BY category_id
> 	
> $$ LANGUAGE SQL;
> 
> SELECT * FROM get_avg_prices_by_prod_categories() AS avg_prices;
> ```
> 
> То что мы пишем в SELECT по порядку сопоставляется тому, что мы написали в аргументах функции. 

Тут мы писали OUT в аргументы функции, но есть другой способ `RETURNS SETOF RECORD`:

> [!example]- RETURNS SETOF *RECORD* без OUT
> ```sql
> CREATE OR REPLACE FUNCTION get_avg_prices_by_prod_categories()
> 		RETURNS SETOF RECORD 
> 		AS $$
> 		
> 	SELECT SUM(unit_price), AVG(unit_price)
> 	FROM products
> 	GROUP BY category_id
> 	
> $$ LANGUAGE SQL;
> 
> SELECT * FROM get_avg_prices_by_prod_categories() AS (sum_price real, avg_price float8);
> ```
> 
> Мы указываем название и типы колонок именно при вызове функции

Этот способ используют, когда на этапе создания не знают, что именно будут возвращать при вызове. Но лучше этого избегать, это неудобно


---


> [!example]- RETURNS TABLE
> ```sql
> CREATE OR REPLACE FUNCTION get_customer_by_country(customer_country varchar)
> 		RETURNS TABLE(char_code char, company_name varchar) AS $$
> 		
> 	SELECT customer_id, company_name
> 	FROM customers
> 	WHERE country = customer_country
> 	
> $$ LANGUAGE SQL;
> 
> SELECT * FROM get_customer_by_country('USA');
> ```
> 
> Самый удобный вариант получения данных с функции, аргументы сопоставляются селекту, названия результирующих колонок также берется из аргументов. 


> [!example]- RETURNS SETOF *table*
> ```sql
> CREATE OR REPLACE FUNCTION get_customer_by_country(customer_country varchar)
> 		RETURNS SETOF customers AS $$
> 		
> 	SELECT *
> 	FROM customers
> 	WHERE country = customer_country
> 	
> $$ LANGUAGE SQL;
> 
> SELECT * FROM get_customer_by_country('USA');
> SELECT contact_name AS contact FROM get_customer_by_country('Germany');
> ```
> 
> Здесь в функции мы пишем SELECT \*, чтобы получить всё и далее уже можем выбирать при вызове, что именно мы хотим получать из таблицы
