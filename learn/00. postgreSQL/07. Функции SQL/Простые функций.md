## Написание простых функций.

Начнем с малого. Возьмем такой код:
```sql
SELECT *
INTO tmp_customers
FROM customers
--сделали временную копию нашей таблицы customers 

UPDATE tmp_customers
SET region = 'unknown'
WHERE region IS NULL;
--везде где регион = null, вставим значение 'unknown'
```

Обычные запросы, ничего особенного. Мы можем сделать функцию, которая будет выполнять наш код при вызове:

> [!example]- Создание простой функции
> ```sql
> CREATE OR REPLACE FUNCTION unknown_customer_region() RETURNS void AS $$
> 	UPDATE tmp_customers
> 	SET region = 'unknown'
> 	WHERE region IS NULL
> $$ language SQL;
> 
> --вызвать ее можем написав:
> 
> SELECT unknown_customer_region()
> ```
> Тут наша функция ничего не принимает и не возвращает (void), только лишь обновляет данные таблицы

- 

> [!example]- Функция, возвращающая значение *bigint*
> ```sql
> CREATE OR REPLACE FUNCTION get_total_number_of_goods() RETURNS bigint AS $$
> 	SELECT SUM(units_in_stock)
> 	FROM products
> $$ language SQL;
> 
> SELECT get_total_number_of_goods() AS total_goods;
> ```
> Тут уже мы возвращаем значение типа *bigint*, а также даем этой возвращаемой колонке название total_goods



> [!example]- Функция, возвращающая значение *float8*
> ```sql
> CREATE OR REPLACE FUNCTION get_avg_price() RETURNS float8 AS $$
> 	SELECT AVG(unit_price)
> 	FROM products
> $$ language SQL;
> 
> SELECT get_avg_price() AS avg_price;
> ```
> Здесь мы возвращаем значение типа *float8* (средняя цена), а также даем этой возвращаемой колонке название avg_price
