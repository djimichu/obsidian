## Функции с аргументами.

Разобрались в функциях без аргументов, теперь пора и с ними разобрать.


- IN - входящие аргументы (явно не прописывают)
- OUT - исходящие аргументы
- INOUT - и входящий и исходящий аргумент (не используем)
- VARIADIC - массив входящих параметров
- DEFAULT *value* 


> [!example] Функция с аргументом prod_name
> ```sql
> CREATE OR REPLACE FUNCTION get_product_price_by_name(prod_name varchar) RETURNS real AS $$
> 	SELECT unit_price
> 	FROM products
> 	WHERE product_name = prod_name
> $$ LANGUAGE SQL;
> 
> SELECT get_product_price_by_name('Chocolade') as price
> ```
> Создаем функцию с аргументом prod_name, используем prod_name в условии, а потом при вызове передаем нужный параметр  'Chocolade'

> [!example] Функция с аргументом prod_name
> ```sql
> CREATE OR REPLACE FUNCTION get_price_boundaries(OUT max_price real,  
> OUT min_price real) AS $$
> 	SELECT MAX(unit_price), MIN(unit_price)
> 	FROM products
> $$ LANGUAGE SQL;
> 
> SELECT get_price_boundaries(); -- или:
> SELECT * FROM get_price_boundaries();
> ```

Смотрим, в первом коде мы писали RETURNS и возвращали одно значение, а во втором коде мы используем OUT для определения типа аргумента. То есть если нам надо вернуть лишь одно значение, то нам хватит RETURNS, но если 2 и более, то используем OUT, как во втором случае.

> [!example]- Реальный вариант этого кода на работе:
> ```sql
> CREATE OR REPLACE FUNCTION get_price_boundaries() 
> RETURNS TABLE(max_price real, min_price real) --разбираем в следующей теме
> AS $$
>     SELECT MAX(unit_price), MIN(unit_price)
>     FROM products;
> $$ LANGUAGE SQL;
> 
> -- Вызов:
> SELECT * FROM get_price_boundaries();
> ```

Для входящего аргумента можно присвоить дефолтное значение, чтобы не указывать его явно при вызове функции:
```sql
CREATE OR REPLACE FUNCTION get_price_boundaries(is_discontinued bool DEFAULT true)
```
