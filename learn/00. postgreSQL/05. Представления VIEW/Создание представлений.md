## Создание VIEW


На примере будем использовать таблицу northwind

> [!example]- Создаем View из трех разных таблиц:
> ```sql
> CREATE VIEW products_suppliers_categories AS
> SELECT product_name, quantity_per_unit, unit_price, units_in_stock,
> s.company_name, s.contact_name, s.phone,
> c.category_name, c.description
> FROM products
> JOIN suppliers AS s USING(supplier_id)
> JOIN categories AS c USING(category_id)
> ```

> [!example] Проверяем:
> ```sql
>  SELECT *
>  FROM products_suppliers_categories
> ```
> Получаем таблицу, которая является представлением тех наших таблиц
