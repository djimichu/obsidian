## Представления (View)

Тут мы поговорим о таком виде объектов как вьюшки.

- ##### **View - это сохранённый запрос в виде объекта в БД (виртуальная таблица)**
- К View можно делать обычный запрос SELECT
- Views можно соединять (JOIN) и т.д.
- Производительность вьюшки такая же, как и у обычной таблице
- Позволяет делать кеширование с помощью материализации (позже...)
- Позволяет сокращать сложные запросы, как подзапросы
- Позволяет подменить реальную таблицу
- Позволяет создавать виртуальные таблицы соединяющие несколько таблиц
- Позволяет скрыть логику агрегации данных при работе через ORM
- Позволяет скрыть информацию (столбцы) от групп пользователей
- Позволяет скрыть информацию на уровне строк от групп пользователей (строки отсекаются самим запросом), то есть можно использовать как фильтр

---

Представления бывают нескольких типов:
- Временные
- Рекурсивные
- Обновляемые
- Материализуемые (хранимая копия данных, как таблица)

---

> [!example] View создается следующим синтаксисом:
> 
> ```sql
> CREATE VIEW view_name AS
> SELECT select_statement
> ```
> Сохраняется запрос с названием view_name


---

View налагает определенные ограничения:
 - Можно лишь добавлять новые столбцы
	 - нельзя удалить существующие
	 - нельзя поменять имена столбцов
	 - нельзя поменять даже порядок следования столбцов

Однако, мы можем заменить вьюшку, с помощью следующего синтаксиса:

> [!example] Меняем запрос
> ```sql
> CREATE OR REPLACE VIEW view_name AS
> SELECT select_statement
> ```
> 
При этом, мы должны помнить о ограничениях, описанных выше

Но мы можем переименовывать сами представления:

> [!example]
> ```sql
> ALTER VIEW old_view_name RENAME TO new_view_name
> ```
> 

Также можем и удалять вьюшки:

> [!example] Удаление
> ```sql
> DROP VIEW IF EXISTS view_name
> ```

---
Модификация данных через представления возможна только при соблюдении условий:
- Только одна таблица в FROM
- Нет DISTINCT, GROUP BY, HAVING, UNION, INTERSECT, EXCEPT, LIMIT
- Нет оконных и агрегационных функций(MIN, MAX, SUM, COUNT, AVG)
- При этом WHERE не под запретом
