### Подзапросы. Введение

Суть данной темы в том, что запросы бывают логически сложными, настолько сложными, что напрямую не получается взять и реализовать сразу весь запрос, для этого можно написать подзапрос, решающий часть задачи.

Бывают и такие, которые без подзапросов реализовать невозможно, либо крайне затруднительно.
Зачастую, запрос с подзапросом можно переписать так, чтобы избавиться от подзапроса(обычно с помощью соединения), но не всегда это нужно.

Выглядят они следующим образом:
```sql
SELECT company_name
FROM suppliers
WHERE country IN (SELECT DISTINCT country
	              FROM customers)
```
То есть на место скобок подставляется значение, которое получится в результате исполнения запроса в скобках.
Этот же код можно переписать с использованием соединения:
```sql
SELECT DISTINCT suppliers.company_name
FROM suppliers
JOIN customers USING(country)
```
