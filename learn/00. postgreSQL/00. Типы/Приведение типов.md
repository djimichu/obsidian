# Приведение типов.

- Интерпретатор способен сам делать некоторые неявные преобразования:
	```sql
	CREATE OR REPLACE FUNCTION type_testing(money_val float8) RETURNS void AS
	$$
	BEGIN
		RAISE NOTICE 'ran %', money_val --в Messages ЗАМЕЧАНИЕ: ran money_val
	END
	$$ LANGUAGE plpgsql;
	
	SELECT type_testing(0.5); -- получаем: ran 0.5; Тип - float8
	SELECT type_testing(0.5::float4); --получаем: ran 0.5; Тип явно float4
	SELECT type_testing(1); --получаем: ran 0.5; Тип неявно преобразован в float8
	```

- Некоторые типы интерпретатор не может неявно преобразовать, он требует явного преобразования:
	 ```sql
	 CREATE OR REPLACE FUNCTION type_testing(money_val int) RETURNS void AS
	$$
	BEGIN
		RAISE NOTICE 'ran %', money_val -- в Messages ЗАМЕЧАНИЕ: ran money_val
	END
	$$ LANGUAGE plpgsql;
	
	SELECT type_testing(1); -- ran 1; ничего не произошло
	SELECT type_testing(0.5); -- тут ошибка, интерпритатор ждал int, неявное преобразование невозможно, возможно только явное
	SELECT type_testing(0.5::int); -- будет преобразовано к 1
	SELECT type_testing(0.4::int); -- будет преобразовано к 0
	SELECT type_testing(CAST(0.4 AS int)); -- то же самое, что и предыдущее
	  ```

 - Можем проводить операции между текстом и числами:
	 ```sql
	 SELECT 'abc' || 1; -- неявное преобразование 1 в текст: abc1
	 
	 SELECT ' 10 ' = 10 -- неявное преобразование ' 10 ' в число: true
	 ```
