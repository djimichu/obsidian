# Типы данных.

### 📊 **ЦЕЛЫЕ ЧИСЛА (Integer Types)**

| Тип             | Размер  | Диапазон              | Когда использовать                                 |
| --------------- | ------- | --------------------- | -------------------------------------------------- |
| **`SMALLINT`**  | 2 байта | -32,768 до 32,767     | Маленькие числа (возраст, рейтинг 1-10)            |
| **`INTEGER`**   | 4 байта | -2.1 млрд до 2.1 млрд | 99% случаев (ID, счётчики, суммы)                  |
| **`BIGINT`**    | 8 байта | -9.2×10¹⁸ до 9.2×10¹⁸ | Очень большие числа (национальный долг)            |
| **`SERIAL`**    | 4 байта | 1 до 2.1 млрд         | Автоинкремент для PK (устарел, используй IDENTITY) |
| **`BIGSERIAL`** | 8 байта | 1 до 9.2×10¹⁸         | Большой автоинкремент                              |

**Правило:** Всегда `INTEGER`, если точно знаешь что будет мало → `SMALLINT`, если много → `BIGINT`.

---

### 🔢 **ДРОБНЫЕ ЧИСЛА (Decimal Types)**

|Тип|Размер|Точность|Когда использовать|
|---|---|---|---|
|**`DECIMAL(p,s)`** / **`NUMERIC(p,s)`**|переменный|ТОЧНАЯ|**Деньги**, где важен каждый цент|
|**`REAL`**|4 байта|~6 цифр|Быстрые вычисления (температура, координаты)|
|**`DOUBLE PRECISION`**|8 байта|~15 цифр|Научные вычисления (физика, инженерия)|

**Примеры:**

```sql
price DECIMAL(10,2)      -- цена: 999999.99 (10 цифр, 2 после запятой)
temperature REAL          -- 23.5°C (достаточно точно)
pi DOUBLE PRECISION      -- 3.14159265358979 (высокая точность)
```

**Правило:** **Деньги = DECIMAL**, вычисления = REAL/DOUBLE.


---

### 📝 **ТЕКСТ (Text Types)**

|Тип|Описание|Когда использовать|
|---|---|---|
|**`VARCHAR(n)`**|Ограниченная длина|Когда знаешь макс длину (почта, телефон)|
|**`TEXT`**|Неограниченная длина|99% случаев (имена, описания, контент)|
|**`CHAR(n)`**|Фиксированная длина|Редко (коды, флаги фикс длины)|

**Примеры:**

```sql
email VARCHAR(255)        -- почта до 255 символов
description TEXT          -- описание любой длины
country_code CHAR(2)      -- всегда 2 буквы: 'RU', 'US'
```

**Правило:** Всегда `TEXT`, если нужны ограничения → `VARCHAR(n)`.


---

### 📅 **ДАТА И ВРЕМЯ (Date/Time Types)**

|Тип|Формат|Пример|Когда использовать|
|---|---|---|---|
|**`DATE`**|Год-месяц-день|`2024-01-15`|Дни рождения, события|
|**`TIME`**|Часы:минуты:секунды|`14:30:00`|Время встречи|
|**`TIMESTAMP`**|Дата+время|`2024-01-15 14:30:00`|99% случаев (логи, заказы)|
|**`TIMESTAMPTZ`**|Дата+время+часовой пояс|`2024-01-15 14:30:00+03`|Международные системы|

**Правило:** Всегда `TIMESTAMPTZ` если есть пользователи в разных часовых поясах.

---

#### ✅ **БУЛЕВЫ (Boolean)**

|Тип|Значения|Пример|
|---|---|---|
|**`BOOLEAN`**|`TRUE`, `FALSE`, `NULL`|флаги, статусы|

```sql
is_active BOOLEAN DEFAULT TRUE
is_deleted BOOLEAN DEFAULT FALSE
```


---



#### 🎯 **ПРОЧИЕ ВАЖНЫЕ ТИПЫ**

| Тип                      | Для чего            | Пример                        |
| ------------------------ | ------------------- | ----------------------------- |
| **`UUID`**               | Уникальные ID       | `gen_random_uuid()`           |
| **`JSON`** / **`JSONB`** | JSON данные         | `{"name": "John", "age": 30}` |
| **`ARRAY`**              | Массивы             | `INT[]`, `TEXT[]`             |
| **`BYTEA`**              | Бинарные данные     | файлы, картинки               |
| **`MONEY`**              | Деньги (осторожно!) | локализованный формат         |

### 📚 **ПОЛЕЗНЫЕ ФУНКЦИИ ПРЕОБРАЗОВАНИЯ**

```sql
-- Приведение типов
SELECT '100'::INTEGER                -- текст → число
SELECT 100::TEXT                     -- число → текст  
SELECT '2024-01-15'::DATE           -- текст → дата
SELECT NOW()::DATE                   -- timestamp → дата

-- Проверка типа
SELECT pg_typeof(column_name)
```
