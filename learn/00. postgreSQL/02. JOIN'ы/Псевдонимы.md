### Псевдонимы AS

Когда мы пишем код, к примеру:
```sql
SELECT работник_id, зарплата + бонус
FROM сотрудники;
```
Нам бы хотелось получить столбец с читаемым названием, таким, какое мы сами ему присвоим, ну то есть зарплата + бонус = общий доход. И мы можем так сделать написав оператор AS(alias), а затем название для результирующего столбца 'общий_доход' 
```sql
SELECT работник_id, зарплата + бонус AS общий_доход
FROM сотрудники;
```

Это улучшает читаемость и позволяет давать понятные названия результатам вычислений.
Псевдоним действует только в пределах одного запроса!

> Эту штуку нельзя использовать в FROM, WHERE и HAVING, так как во время отработки этих команд псевдонимы еще не назначены. Сначала применяются FROM и WHERE, а только потом отрабатывают SELECT и всё остальное, что собственно логично.
> В GROUP BY и ORDER BY можно использовать псевдонимы, назначенные в SELECT

```sql
SELECT работник_id, зарплата + бонус AS общий_доход
FROM сотрудники;
~~WHERE общий_доход > 1000~~ /так писать нельзя!!!
GROUP BY работник_id
ORDER BY общий_доход /а так можно!
```

> Мы должны всегда использовать псевдонимы в такого рода калькулируемых запросах, это сильно сокращает код и упрощает читабельность!
