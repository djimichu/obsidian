# Логические операторы AND, OR, NOT.

 ### AND:
1. 
	```sql
	SELECT имя, номер
	FROM сотрудники
	WHERE доход > 1000 AND доход < 2000
	```
	В данном условии мы применяем AND как "но".
>[!Пример]-
>доход больше 1000, но меньше 2000
>
| имя     | номер | доход |     | имя     | номер |
| ------- | ----- | ----- | --- | ------- | ----- |
| Василий | 89352 | 1200  |     | Василий | 89352 |
| Николай | 89872 | 900   |     | Алексей | 89356 |
| Андрей  | 89275 | 2100  |     |         |       |
| Петр    | 89125 | 3500  |     |         |       |
| Алексей | 89356 | 1800  |     |         |       |
| Дмитрий | 89156 | 1000  |     |         |       |

2. ```sql
 SELECT имя
 FROM сотрудники
 WHERE доход > 1500 AND страна = 'Россия'
   ```
   А тут уже AND используется как "и":
   >[!Пример]-
>
| имя     | страна   | доход |     | имя    |
| ------- | -------- | ----- | --- | ------ |
| Василий | Украина  | 1200  |     | Андрей |
| Николай | Беларусь | 1900  |     |        |
| Андрей  | Россия   | 2100  |     |        |
| Петр    | Сербия   | 3500  |     |        |
| Алексей | Латвия   | 1800  |     |        |
| Дмитрий | Россия   | 1000  |     |        |

> Eсли в таком запросе выбрать два взаимоисключающих параметра(страна), то результирующий набор ничего нам не отдаст, так как не существует сотрудников, у которых например страна "Россия" и "Сербия" одновременно.
- 

1. ### OR:
	```sql
	SELECT *
	FROM сотрудники
	WHERE страна = 'Россия' OR страна = 'Сербия' OR страна = 'Латвия'
	```
>[!Пример]-
>| имя     | страна   | доход |     | имя    |
| ------- | -------- | ----- | --- | ------ |
| Василий | Украина  | 1200  |     | Андрей |
| Николай | Беларусь | 1900  |     |  Петр |
| Андрей  | Россия   | 2100  |     |   Алексей     |
| Петр    | Сербия   | 3500  |     |        |
| Алексей | Латвия   | 1800  |     |        |
| Дмитрий | Россия   | 1000  |     |        |
