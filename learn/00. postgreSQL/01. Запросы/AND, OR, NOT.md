#AND, #OR, #NOT
# Логические операторы AND, OR, NOT.


---


 ## ==AND:==
1. 
	```sql
	SELECT имя, номер
	FROM сотрудники
	WHERE доход >= 1000 AND доход <= 2000
	```
	В данном условии мы применяем AND как "но".
>[!Пример]-
>доход больше 1000, но меньше 2000
>
| имя     | номер | доход |     | имя     | номер |
| ------- | ----- | ----- | --- | ------- | ----- |
| Василий | 89352 | 1200  |     | Василий | 89352 |
| Николай | 89872 | 900   |     | Алексей | 89356 |
| Андрей  | 89275 | 2100  |     |    Дмитрий     |   89156    |
| Петр    | 89125 | 3500  |     |         |       |
| Алексей | 89356 | 1800  |     |         |       |
| Дмитрий | 89156 | 1000  |     |         |       |

> По факту мы сделали запрос, который переводится как: верни имя и номер, где доход между 1000$ и 2000$ (включительно!!!), и в postgres есть оператор #BETWEEN, который заменяет эту запись.


```sql
	SELECT имя, номер
	FROM сотрудники
	WHERE доход BETWEEN 1000 AND 2000
```
> BETWEEN можно применять и к датам.

- 

2. 
    ```sql
	SELECT имя
	FROM сотрудники
	WHERE доход > 1500 AND страна = 'Россия'
   ```
   А тут уже AND используется как "и":
   >[!Пример]-
>
| имя     | страна   | доход |     | имя    |
| ------- | -------- | ----- | --- | ------ |
| Василий | Украина  | 1200  |     | Андрей |
| Николай | Беларусь | 1900  |     |        |
| Андрей  | Россия   | 2100  |     |        |
| Петр    | Сербия   | 3500  |     |        |
| Алексей | Латвия   | 1800  |     |        |
| Дмитрий | Россия   | 1000  |     |        |

> Eсли в таком запросе выбрать два взаимоисключающих параметра(страна), то результирующий набор ничего нам не отдаст, так как не существует сотрудников, у которых например страна "Россия" и "Сербия" одновременно.


---

## ==OR:==
1. 
	```sql
	SELECT *
	FROM сотрудники
	WHERE страна = 'Россия' OR страна = 'Сербия' OR страна = 'Латвия'
	```
>[!Пример]-
>| имя     | страна   | доход |     | имя    |
| ------- | -------- | ----- | --- | ------ |
| Василий | Украина  | 1200  |     | Андрей |
| Николай | Беларусь | 1900  |     |  Петр |
| Андрей  | Россия   | 2100  |     |   Алексей     |
| Петр    | Сербия   | 3500  |     |    Дмитрий    |
| Алексей | Латвия   | 1800  |     |        |
| Дмитрий | Россия   | 1000  |     |        |

> В данном запросе мы перебираем страны, сотрудников из которых мы хотим получить, но если стран много, то запрос будет выглядеть некрасиво и громоздко, чтобы этого избежать, есть оператор #IN, а также #NOT. Он нам позволяет сделать запись по другому:

```sql
	SELECT имя, номер
	FROM сотрудники
	WHERE страна NOT IN ('Россия', 'Сербия', 'Латвия')
```

> Запрос теперь выведет всех, кто НЕ живет в выделенных странах, читаемость гораздо лучше нежели писать это без данных операторов. Эти оператор могут применяться к разным типам данных!
- 
2. 
    ```sql
    SELECT имя
	FROM сотрудники
	WHERE дата_рождения > '01.01.2000' AND (доход < 1500 OR доход >= 2100)
   ```
   В этом примере мы выбираем только тех, кто родился ПОСЛЕ 01.01.2000 и имеет доход меньше 1500$ или больше(или равно) 2100$.
>[!Пример]-
>
| имя     | страна   | доход | дата_рождения |     | имя     |
| ------- | -------- | ----- | ------------- | --- | ------- |
| Василий | Украина  | 1200  | 02.08.2004    |     | Василий |
| Николай | Беларусь | 1900  | 14.02.1995    |     | Андрей  |
| Андрей  | Россия   | 2100  | 18.03.2005    |     | Дмитрий |
| Петр    | Сербия   | 1500  | 24.12.1996    |     |         |
| Алексей | Латвия   | 1800  | 06.10.2002    |     |         |
| Дмитрий | Россия   | 1000  | 30.12.2000    |     |         |

> Когда по смыслу нам нужно объединить какие-то блоки условий, мы объединяем их скобками: `условие1 AND (условие2 OR условие3)`
