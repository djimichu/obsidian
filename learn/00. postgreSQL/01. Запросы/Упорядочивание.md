# Упорядочивание


---


#ORDER_BY #ASC #DESC

Мы можем упорядочивать наши результаты выборки путем дополнительной строки:
**ORDER BY**, идущей после [[SELECT]], FROM и [[WHERE]]. 
1. 
	```sql
	SELECT DISTINCT страна, город
	FROM сотрудники
	WHERE страна NOT IN('Украина', 'Сербия')
	ORDER BY страна DESC, город ASC
	```

>[!Пример]-
>
| имя      | страна   | город   |     | страна   | город   |
| -------- | -------- | ------- | --- | -------- | ------- |
| Дмитрий  | Россия   | Саратов |     | Украина  | Киев    |
| Николай  | Беларусь | Минск   |     | Украина  | Одесса  |
| Андрей   | Россия   | Анапа   |     | Россия   | Анапа   |
| Петр     | Беларусь | Гомель  |     | Россия   | Саратов |
| Алексей  | Украина  | Одесса  |     | Беларусь | Гомель  |
| Василий  | Украина  | Киев    |     | Беларусь | Минск   |
| Владимир | Беларусь | Минск   |     |          |         |




> Из примера видно, что страны отсортированы ***по убыванию(descending) - DESC***,
> а города ***по возрастанию(ascending) - ASC***
> Если написать без ASC и DESC, то по умолчанию будет отсортировано по ASC(по возрастанию).
> 
> Это работает со всеми типами данных.
