Мы получаем данные с помощью запроса #SELECT (Выбрать):

1.  **Полная выборка**:
	 ```sql
	SELECT * 
	FROM название_таблицы;
	 ```

- 

2.   **Частичная выборка**:
	 ```sql
	SELECT столбец1, столбец2 
	FROM название_таблицы;
	 ```

- 

3. Мы можем получать данные, которые будут **результатом** каких-то **вычислений**(+, -, /, *, %, ^, |/(кв. корень) и т.д.):
	```sql
	SELECT столбец1, зарплата + бонус AS общий_доход
	FROM сотрудники;
	```
>  Притом если мы совершим невозможную операцию(int + char), получим
> ОШИБКА: оператор не существует: character + integer  


---

#DISTINCT
1.  **DISTINCT** - если нужно получить данные без дубликатов(например, в таблице много повторений, но нам нужно каждое значение по 1 разу)
	```sql
	SELECT DISTINCT страна, город
	FROM сотрудники;
	```
	у нас не будет ни одного дубликата, будут уникальные строки страна-город

> [!пример]- 
| Страна   | Город   |     | Страна   | Город   |
| -------- | ------- | --- | -------- | ------- |
| Россия   | Москва  |     | Россия   | Москва  |
| Беларусь | Минск   |     | Беларусь | Минск   |
| Россия   | Москва  |     | Россия   | Саратов |
| Россия   | Саратов |     |          |         |
| Россия   | Москва  |     |          |         |
  
- 

#COUNT

2. **COUNT** - агрегатная функция, для подсчета количества строк (если нужно получить кол-во записей в столбце)
	```sql
	SELECT COUNT(страна) AS кол-во
	FROM сотрудники;
	
	SELECT COUNT(DISTINCT страна) AS кол-во
	FROM сотрудники;
	```
	В первом запросе мы запросили общее число строк, а во втором мы берем число уникальных строк, которые не повторяются

> [!Пример]- 
> 
| Страна   |     | cnt |     | Страна   |     | cnt |
| -------- | --- | --- | --- | -------- | --- | --- |
| Россия   |     | 6   |     | Россия   |     | 4   |
| Китай    |     |     |     | Китай    |     |     |
| Беларусь |     |     |     | Беларусь |     |     |
| Россия   |     |     |     | Россия   |     |     |
| Монголия |     |     |     | Монголия |     |     |
| Беларусь |     |     |     | Беларусь |     |     |
