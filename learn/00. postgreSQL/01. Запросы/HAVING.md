### ==HAVING== - структурная часть запроса, вторичный фильтр

Иногда необходимо после каких-то операций в запросе применить сперва один фильтр, а потом по отфильтрованному результату применить повторно уже другой фильтр. Для этого есть вторичный фильтр - #HAVING.
Допустим посчитать сумму товаров, соответствующих первому условию, а потом получить только суммы товаров, которые больше 1000$

1. 
	```sql
	SELECT товар, SUM(цена * кол-во)
	FROM комплектующие
	WHERE онлайн_продажи != false
	GROUP BY категория
	```
>[!Пример]-
>Имеем таблицу с категориями товаров, какие-то продаются онлайн, какие-то - нет.
> Получаем сумму товаров продающихся онлайн по категориям, всё как обычно:
>
| категория | товар         | кол-во | цена | онлайн |     | категория | сумма |
| --------- | ------------- | ------ | ---- | :----: | --- | --------- | ----- |
| 1         | Видеокарты    | 9      | 500  | false  |     | 1         | 9050  |
| 1         | Процессоры    | 21     | 350  |  true  |     | 2         | 4070  |
| 1         | Жесткие диски | 34     | 70   | false  |     | 3         | 3000  |
| 1         | Блоки питания | 17     | 100  |  true  |     |           |       |
| 2         | Мониторы      | 8      | 400  | false  |     |           |       |
| 2         | Клавиатуры    | 25     | 50   |  true  |     |           |       |
| 2         | Игровые мыши  | 47     | 60   |  true  |     |           |       |
| 3         | Наушники      | 20     | 150  |  true  |     |           |       |
| 3         | Телефоны      | 23     | 700  | false  |     |           |       |

Но допустим нам надо получить суммы не всех категорий, а только тех, что стоят болеe 3500$ и мы можем написать это в одном запросе:
```sql
	SELECT товар, SUM(цена * кол-во)
	FROM комплектующие
	WHERE онлайн_продажи != false
	GROUP BY товар
	HAVING SUM(цена * кол-во) > 3500
	ORDER BY SUM(цена * кол-во) DESC
```
>[!Пример]-
>Теперь мы имеем таблицу. которая соответствует вторичному условию HAVING, а также отсортированную по убыванию сумм категорий:
