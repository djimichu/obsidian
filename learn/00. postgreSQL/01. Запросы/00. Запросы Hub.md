# Все SQL запросы

## Запросы на чтение:


1. SELECT имя
2. FROM таблица
3. WHERE условие
4. GROUP BY имя
5. HAVING условие_2
6.  ORDER BY
7. LIMIT 100



- [[SELECT]] - выборка данных
- [[WHERE]] - фильтрация
- [[AND, OR, NOT]] - логические операторы
- [[Упорядочивание]] выбранных данных
- [[Скалярные функции]] 
- [[Matching LIKE]] - фильтр для поиска строк соответствующих заданному шаблону
- [[LIMIT]] - получить из всего результата запроса только первые N записей
