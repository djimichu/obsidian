# Все SQL запросы

## Запросы на чтение:


1. SELECT имя
2. FROM таблица
3. WHERE условие_1 AND/OR условие_2
4. GROUP BY имя группы
5. HAVING условие_3
6. ORDER BY сортировка
7. LIMIT 100



- [[SELECT]] - выборка данных

- [[WHERE]] - фильтрация

- [[HAVING]] - вторичная фильтрация

- [[AND, OR, NOT]] - логические операторы

- [[Упорядочивание]] выбранных данных

- [[Скалярные функции]] - SUM, MAX, MIN, AVG

- [[GROUP BY]] - группирование результатов по заданному критерию

- [[Matching LIKE]] - фильтр для поиска строк соответствующих заданному шаблону

- [[LIMIT]] - получить из всего результата запроса только первые N записей

-  [[UNION, INSERSECT, EXCEPT]] - операции над множествами (объединение(UNION), пересечения(INSERSECT) и исключения(EXCEPT))
