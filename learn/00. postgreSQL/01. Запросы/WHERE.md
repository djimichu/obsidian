#WHERE
## Первичный фильтр - ==WHERE==


---


Фильтрация в запросе применяется со всеми типами при помощи операторов сравнения: a = b, a >= b, a <= b, a < b, a > b,    *a <> b, a != b*  (последние две это одно и то же!)

1. ```sql
	SELECT имя_работника, номер_телефона
	FROM сотрудники;
	WHERE страна <> 'Россия'
   ```
   
   > Если в *строковом литерале* ('Россия') есть ' то мы экранируем её еще одной ': 'parameter''s'


> [!example]- 
> 
| имя     | номер | страна  |     | имя     | номер |
| ------- | ----- | ------- | --- | ------- | ----- |
| Василий | 89352 | Россия  |     | Николай | 89872 |
| Николай | 89872 | Китай   |     | Андрей  | 89275 |
| Андрей  | 89275 | США     |     | Алексей | 89356 |
| Петр    | 89125 | Россия  |     |         |       |
| Алексей | 89356 | Вьетнам |     |         |       |
| Дмитрий | 89156 | Россия  |     |         |       |


2. ```sql
	SELECT имя_работника, номер_телефона
	FROM сотрудники;
	WHERE доход < 1000
   ```

> [!example]- 
> 
| имя     | номер | доход |     | имя     | номер |
| ------- | ----- | ----- | --- | ------- | ----- |
| Василий | 89352 | 1200  |     | Николай | 89872 |
| Николай | 89872 | 900   |     | Дмитрий | 89156 |
| Андрей  | 89275 | 1500  |     |         |       |
| Петр    | 89125 | 1000  |     |         |       |
| Алексей | 89356 | 1100  |     |         |       |
| Дмитрий | 89156 | 700   |     |         |       |


---

Также вместе с WHERE мы можешь применить фильтр IS NULL, и в таком случае мы получим все записи, в которых записан null (отсутствие данных):

3. ```sql
	SELECT имя_работника, номер_телефона
	FROM сотрудники;
	WHERE номер IS NULL
   ```

> [!example]- 
> Получаем все записи, где номер = null
> 
| имя     | номер | доход |     | имя     | номер |
| ------- | ----- | ----- | --- | ------- | ----- |
| Василий | null | 1200  |     | Василий | null |
| Николай | 89872 | 900   |     | Петр | null |
| Андрей  | 89275 | 1500  |     |    Алексей     |   null    |
| Петр    | null | 1000  |     |         |       |
| Алексей | null | 1100  |     |         |       |
| Дмитрий | 89156 | 700   |     |         |       |


> Если использовать IS NOT NULL, то соответственно получим все записи, где номер != null. 

---
> Вместе с WHERE также применяются логические операторы [[AND, OR, NOT]].
