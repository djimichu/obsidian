### ==LIMIT==

Допустим в нашей таблице 1000 записей, но нам нужно посмотреть только на первые 10 записей этой таблицы, для этого у нас есть ключевое слово #LIMIT. Оно пишется в самом конце, после всех строк запроса! То есть мы можем писать те же любые параметры, условия, а потом написать LIMIT n, и в результате будет либо n записей, либо меньше n, если записей меньше.


1. 
	```sql
	SELECT имя, номер
	FROM сотрудники
	WHERE имя != 'Вадим'
	ORDER BY имя ASC
	```
>[!example]-
>Имена, кроме 'Вадим' по возрастанию:
>
| имя     | номер | доход |     | имя     | номер |

| Василий | 89352 | 1200  |     | Адам | 89275 |
| Вадим | 89872 | 900   |     | Алексей | 89356 |
| Адам  | 89275 | 2100  |     |    Василий     |   89352    |
| Петр    | 89125 | 3500  |     |     Дмитрий    |   89156    |
| Алексей | 89356 | 1800  |     |    Петр     |    89125   |
