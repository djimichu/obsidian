### Pattern Matching with ==LIKE==


---
Допустим нам необходимо получить все данные, в которых есть что-то общее в строке, например все номера, начинающиеся с 8.937, общий критерий может быть где угодно. 
Для этого у нас есть оператор #LIKE

Есть два wildcard'а/placeholder'а(заполнительный знак):
% - означающий 0, 1 и более символов
_ - ровно 1 любой символ

- LIKE 'U%' - строки, начинающиеся с U
- LIKE '%a' - строки, кончающиеся на а
- LIKE '%John%' - строки, содержащие John
- LIKE 'J%n' - строки, начинающиеся с J, и кончающиеся на n

- LIKE '\_oh\_' -   строки, где 2, 3 символы - oh, а первый(1) и последний(4) - любые
- LIKE '\_oh%' - строки, где 2, 3 символы - oh, первый - любой и в конце 0, 1 и более любых символов


---

1. 
	```sql
	SELECT имя, номер
	FROM сотрудники
	WHERE имя LIKE '%ий'
	```
>[!Пример]-
>Имена, заканчивающиеся на 'ий':
>
| имя     | номер | доход |     | имя     | номер |
| ------- | ----- | ----- | --- | ------- | ----- |
| Василий | 89352 | 1200  |     | Василий | 89352 |
| Вадим | 89872 | 900   |     | Дмитрий | 89156 |
| Адам  | 89275 | 2100  |     |         |       |
| Петр    | 89125 | 3500  |     |         |       |
| Алексей | 89356 | 1800  |     |         |       |
| Дмитрий | 89156 | 1000  |     |         |       |

2. 
	```sql
	SELECT имя, номер
	FROM сотрудники
	```

| имя     | номер | доход |     | имя     | номер |

| Петр    | 89125 | 3500  |     |         |       |
| Алексей | 89356 | 1800  |     |         |       |
| Дмитрий | 89156 | 1000  |     |         |       |

3. 
	```sql
	SELECT имя, номер
	FROM сотрудники
	```
