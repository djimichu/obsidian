### ==GROUP BY==

Мы можем группировать наши результаты запроса по каким-то критериям благодаря структурной вставки #GROUP_BY.

1. 
	```sql
	SELECT страна, COUNT(*)
	FROM сотрудники
	WHERE доход > 1000
	GROUP BY страна
	```
>[!Пример]-
>Группируем по странам число работников с зп больше 1000$:
>
| имя     | страна | доход |     | страна     | cnt |
| ------- | ----- | ----- | --- | ------- | ----- |
| Василий | Беларусь | 1200  |     | Беларусь | 1 |
| Вадим | Россия | 900   |     | Россия | 3 |
| Адам  | Россия | 2100  |     |    Норвегия     |   1    |
| Петр    | Норвегия | 3500  |     |         |       |
| Алексей | Россия | 1800  |     |         |       |
| Дмитрий | Беларусь | 1000  |     |         |       |


2. 
	```sql
	SELECT страна, COUNT(*)
	FROM сотрудники
	WHERE доход > 1000
	GROUP BY страна
	ORDER BY COUNT(*) ASC
	```
>[!Пример]-
>Группируем по странам число работников с зп больше 1000$ и сортируя по количеству:
>
| имя     | страна | доход |     | страна     | cnt |
| ------- | ----- | ----- | --- | ------- | ----- |
| Василий | Россия | 1200  |     | Россия | 3 |
| Вадим | Беларусь | 900   |     | Беларусь | 1 |
| Адам  | Россия | 2100  |     |    Норвегия     |   1    |
| Петр    | Норвегия | 3500  |     |         |       |
| Алексей | Россия | 1800  |     |         |       |
| Дмитрий | Беларусь | 1000  |     |         |       |
