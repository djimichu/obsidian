# Скалярные функции


---


Самые популярные скалярные функции используются для вычисления максимального значения - #MAX, минимального - #MIN и среднего - #AVG. Также можем получить сумму #SUM. Работает ТОЛЬКО с числами(MAX, MIN работает и с датами). 

### MAX 
1. 
	```sql
	SELECT MAX(дата_рождения)
	FROM сотрудники
	WHERE страна != 'Латвия'
	```
>[!example]-
>
| имя     | страна   | дата_рождения |     | max        |
| ------- | -------- | ------------- | --- | ---------- |
| Василий | Украина  | 02.08.2004    |     | 18.03.2005 |
| Николай | Беларусь | 14.02.1995    |     |            |
| Андрей  | Россия   | 18.03.2005    |     |            |
| Петр    | Сербия   | 24.12.1996    |     |            |
| Алексей | Латвия   | 06.10.2015    |     |            |
| Дмитрий | Россия   | 30.12.2000    |     |            |

- 
### MIN
1. 
	```sql
	SELECT MIN(дата_рождения)

	WHERE страна != 'Латвия'
	```

| имя     | страна   | дата_рождения |     | min        |
| ------- | -------- | ------------- | --- | ---------- |

| Алексей | Латвия   | 06.10.1992    |     |            |

### AVG
1. 
	```sql
	SELECT AVG(доход)
	FROM сотрудники
	WHERE страна = 'Россия'
	```
>[!example]-
>
| имя     | страна   | доход |     | avg  |
| ------- | -------- | ----- | --- | ---- |
| Василий | Россия   | 1000  |     | 3000 |
| Николай | Россия   | 2000  |     |      |
| Андрей  | Россия   | 3000  |     |      |
| Петр    | Россия   | 4000  |     |      |
| Алексей | Россия   | 5000  |     |      |
| Дмитрий | Беларусь | 6000  |     |      |

- 

### SUM
1. 
	```sql
	SELECT SUM(доход)
	FROM сотрудники
	WHERE страна = 'Россия'
	```
>[!example]-
>Условная сумма затрат на зп всем сотрудникам
> 
| имя     | страна   | доход |     | sum  |
| ------- | -------- | ----- | --- | ---- |

| Николай | Россия   | 2000  |     |      |

| Петр    | Россия   | 4000  |     |      |
| Алексей | Россия   | 5000  |     |      |
