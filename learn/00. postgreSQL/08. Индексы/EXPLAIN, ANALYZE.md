## EXPLAIN

EXPLAIN (объяснять)
- Если есть проблема с производительностью - надо понять откуда "растут ноги"
- EXPLAIN *query* позволяет посмотреть на план выполнения запроса(оценка планировщика)
	```sql
	EXPLAIN
	SELECT order_id, order_date, COALESCE(ship_region, 'unknown') AS ship_region
	FROM orders
	LIMIT 10 --рандомный запрос для примера без индексов
	```

cost - накладные расходы, предполагаемые планировщиком, как долго будет исполняться некий statement(утверждение запроса). Сумма затрат на работу диска и CPU
- EXPLAIN ANALYZE *query* прогоняет запрос, показывает план и реальность

## ANALYZE

- Собирает статистику по данным таблицы(укладывает результаты в pg_statistic таблицу)
- Планировщик смотрит на статистику при построении плана
- ANALYZE \[*table_name*\[(*column1*, *column2...*)]]
- Запускать как минимум один раз в день
- autovacuum (если включен) в том числе запускает ANALYZE
