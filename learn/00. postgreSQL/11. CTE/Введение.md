# CTE - Common Table Expressions

Общие табличные выражения

- Позволяют строить временные таблицы (или представления) в рамках большого запроса
- Присваивая имя такой временной таблице (подзапросу), мы можем её переиспользовать
- ```sql
  WITH name AS (
		SELECT clause
	)
	SELECT "using WITH part"
  ```
- Внутри подзапроса можно использовать `INSERT`, `UPDATE`, `DELETE`
- CTE выполняется единожды, результат кэшируется (не всегда, см. план выполнения)
- Длинные и сложные запросы можно отрефакторить в CTE, повышая чистоту и читабельность кода


> [!tip]- Пример
> Найти поставщиков, страны которых, присутствуют в списке стран, где у нас заказчики
> ```sql
> SELECT * 
> FROM suppliers
> WHERE country IN (SELECT country FROM customers);
> --первый вариант с подзапросом
> 
> WITH customer_countries AS
> (
> 	SELECT country FROM customers
> )
> SELECT company_name
> FROM suppliers
> WHERE country IN (SELECT * FROM customer_countries);
> --второй вариант с CTE
> ```
> > Кажется, что первый проще, и это правда, но это для примера, потом могут быть запросы куда более сложные, и в том случае будет куда проще сделать с WITH нежели писать огромные подзапросы

## Рекурсивные CTE

Рекурсия похожа на суть SELF JOIN. Когда нам нужна #иерархия в одной таблице, может быть полезна рекурсивная CTE.
```sql
WITH RECURSIVE submission(sub_line, employee_id) AS
(
	SELECT last_name, employee_id FROM employee WHERE manager_id IS NULL
	UNION ALL
	SELECT sub_line || ' -> ' || e.last_name, e.employee_id
	FROM employee e, submission s
	WHERE e.manager_id, e.employee_id
)

SELECT * FROM submission;
```

> [!tip]- Что делает:
> 1. Находит всех, у кого нет начальника (глава компании)
>     
> 2. Для каждого такого человека ищет его прямых подчиненных
>     
> 3. Для подчиненных ищет их подчиненных и т.д.
>     
> 4. Строит строку типа `"Smith -> Johnson -> Lee"`
